# Ankit Design Studio
A lightweight, responsive, traditional multi-page website built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Replace portfolio visuals
The portfolio uses CSS placeholders so actual JPG/PNG artwork can be added later in `images/portfolio/`, then referenced from the relevant cards in `portfolio.html`.

## Contact placeholders
Update the clearly labelled WhatsApp, Instagram, Behance and Email placeholders in `contact.html` before publishing. The included form validates client-side only and does not send email without a backend integration.
